# vps-claude-setup

Bootstrap-скрипт первичной настройки VPS на **Virtarix** (сервер `146.103.57.168`,
Ubuntu 24.04) для работы с **Claude**.

Помимо самого Claude Code скрипт поднимает на сервере **WireGuard VPN (wg-easy)** —
claude.ai недоступен из РФ напрямую, поэтому регистрация и вход в Claude выполняются
через VPN-туннель до этого же сервера.

## Быстрый старт

```bash
ssh root@146.103.57.168
curl -fsSL https://raw.githubusercontent.com/san4ess1981-blip/vps-claude-setup/main/setup.sh -o setup.sh
bash setup.sh
```

Скрипт идемпотентен: повторный запуск пропускает уже выполненные шаги.

> ⚠️ После отработки скрипта SSH переезжает на порт **51222** (порт 22 закрывается).
> Не закрывая текущую сессию, проверьте вход: `ssh -p 51222 dev@146.103.57.168`.

## Что делает скрипт

| Шаг | Содержание |
|---|---|
| 1 | Обновление системы, базовые пакеты, автообновления безопасности |
| 2 | Создание sudo-пользователя `dev` (случайный пароль), копирование SSH-ключей root |
| 3 | Файрвол UFW + fail2ban (jail sshd на новом порту) |
| 3.5 | **Защита SSH**: порт `51222` вместо 22, `AllowUsers dev root`, root только по ключу, `PasswordAuthentication no` — при наличии SSH-ключа (без ключа пароль остаётся, чтобы не потерять доступ); отключение socket-активации Ubuntu 24.04; откат конфига при ошибке |
| 4 | Docker |
| 5 | WireGuard VPN с веб-панелью **wg-easy** (пароль панели генерируется случайно) |
| 6 | Node.js 22 LTS + `npm i -g @anthropic-ai/claude-code` |
| 6.5 | SSH-ключ для GitHub у пользователя `dev` + удобный алиас в `~/.ssh/config` |
| 7 | Сводка с паролями и следующими шагами → `/root/setup-summary.txt` |

Параметры (имя пользователя, порт SSH, порты VPN, IP) меняются в шапке скрипта.

## Проверка установки

После `setup.sh` проверьте сервер скриптом `check.sh` — он запускается
**с локальной машины**, подключается по SSH и проверяет каждый шаг:

```bash
curl -fsSL https://raw.githubusercontent.com/san4ess1981-blip/vps-claude-setup/main/check.sh -o check.sh
bash check.sh                              # root@146.103.57.168, порт 51222
bash check.sh dev@146.103.57.168           # другой пользователь/хост
bash check.sh root@146.103.57.168 51222    # явно указать SSH-порт
```

Что проверяется: пользователь `dev` и его группы, базовые пакеты, защита SSH
(порт, `AllowUsers`, `PermitRootLogin`, `PasswordAuthentication`), UFW (порты
51222/51820/51821, закрытие 22-го), fail2ban, Docker, контейнер и панель wg-easy,
Node.js ≥ 22, Claude Code, SSH-ключ для GitHub. Код выхода `0` — всё в порядке,
`1` — есть проблемы (строки `[FAIL]`). Для полной проверки нужен root-доступ.

## После установки

1. Откройте панель wg-easy: `http://146.103.57.168:51821`, создайте клиента и
   импортируйте конфиг в WireGuard на домашнем ПК.
2. **С включённым VPN** войдите на claude.ai.
3. Закройте панель снаружи: `sudo ufw deny 51821/tcp`.
4. Работа с Claude Code:

```bash
ssh -p 51222 dev@146.103.57.168
tmux new -s work   # сессия переживёт отключение SSH
claude             # ссылку авторизации открыть в браузере С VPN
```

5. Добавьте публичный SSH-ключ (из `/root/setup-summary.txt`) в
   https://github.com/settings/ssh/new — для push/pull с сервера.
6. Чтобы полностью отключить вход по паролю: положите свой публичный ключ в
   `/home/dev/.ssh/authorized_keys` и перезапустите `setup.sh`.
7. Сделайте снапшот в панели Virtarix.

## Безопасность

- Пароли и ключи существуют только на сервере (`/root/setup-summary.txt`) —
  после сохранения удалите этот файл с сервера.
- Не коммитьте в репозиторий ключи, пароли и конфиги WireGuard.
- Скрипт не отключит парольный вход, пока на сервере нет ни одного SSH-ключа —
  защита от самоблокировки встроена.
