# Большая простая шпаргалка: чиним сервер с нуля

Прочти сначала этот блок — и всё будет понятно.

**Что вообще происходит?** У тебя есть арендованный удалённый компьютер
(он называется «сервер», адрес у него `146.103.57.168`). Он стоит где-то в дата-центре
и работает круглосуточно. Мы хотим, чтобы на нём работала программа Claude.

**Что сломалось?** Обычный способ подключиться к серверу (он называется SSH)
сейчас не работает с твоего компьютера — соединение обрывается. Скорее всего,
сервер «завален» тысячами попыток взлома от роботов из интернета (это нормально,
так происходит с любым сервером) или мешает фильтр на линии провайдера.

**Как починим?** Зайдём на сервер через «запасной вход» — экран удалённого
компьютера прямо в браузере (это называется консоль VNC, она есть в панели
Virtarix и работает всегда). Там выполним волшебные заклинания (команды),
которые:

1. положат на сервер твой **ключ** — это как особый электронный пропуск,
   после чего твой компьютер будет входить на сервер без пароля;
2. перенесут вход на **другую дверь** (порт 51222 вместо 22) — роботы-взломщики
   стучатся только в старую дверь, про новую не знают;
3. установят VPN (чтобы Claude работал из России) и саму программу Claude.

**Правила игры:**

- Команды из серых рамок **копируй и вставляй целиком**, ничего в них не меняй.
- После вставки команды нажми **Enter**.
- Если что-то пошло не так — не страшно, в конце есть раздел «Аварийный выход».

---

## Что понадобится

1. Логин и пароль от панели **Virtarix** (сайт, где ты арендовал сервер).
2. **Пароль root** от сервера (Virtarix прислал его при создании сервера —
   посмотри в панели или в письме).
3. Эта шпаргалка, открытая рядом.
4. 30–40 минут времени.

---

## Шаг 1. Открыть «экран» сервера в браузере

1. Зайди на сайт **virtarix.com** и войди в личный кабинет.
2. Найди свой сервер в списке и открой его.
3. Найди кнопку **Console** (или **VNC**, **Консоль**) и нажми.
4. Откроется чёрное окно — это экран сервера, как будто к нему подключён
   монитор и клавиатура.

Если окно просит `login:` — напечатай `root`, нажми Enter.
Когда спросит `Password:` — напечатай пароль root и нажми Enter.
**Внимание:** при вводе пароля на экране НИЧЕГО не появляется — ни звёздочек,
ни точек. Это нормально, так задумано. Просто печатай вслепую и жми Enter.

✅ **Как понять, что получилось:** появилась строка вида `root@...:~#`
и мигает курсор. Ты внутри сервера!

> ⚠️ **ОЧЕНЬ ВАЖНО — клавиатура!** Чёрное окно в браузере понимает только
> **английскую раскладку**. Если у тебя включён русский язык, символы
> `/`, `>`, `:` превратятся в `?`, `.` и другие — и все команды сломаются.
>
> Перед вводом команд переключи клавиатуру на английский:
> **Win + Пробел** → выбери **ENG** (английская раскладка США).
>
> **Проверка:** напечатай в консоли `echo /` и нажми Enter.
> Должна появиться строка `/`. Если видишь `?` — раскладка всё ещё русская,
> переключи ещё раз.

---

## Шаг 2. Положить на сервер электронный пропуск (ключ)

Скопируй эти четыре команды **по одной**, вставляй в чёрное окно и жми Enter
после каждой:

```bash
mkdir -p /root/.ssh
```

```bash
echo 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJ0MUro6K+mAYk0yuKbC88lM6MGCIpNQYEYJHQJCkLyP admin-home-pc' >> /root/.ssh/authorized_keys
```

```bash
chmod 700 /root/.ssh
```

```bash
chmod 600 /root/.ssh/authorized_keys
```

**Что это было, простыми словами:** мы создали на сервере папку-сейф,
положили туда твой пропуск и закрыли сейф от посторонних.

**Проверка.** Выполни команду:

```bash
cat /root/.ssh/authorized_keys
```

✅ **Правильно:** на экране появилась **одна длинная строка**, которая
начинается с `ssh-ed25519` и заканчивается `admin-home-pc`.
❌ **Неправильно:** строк несколько, строка оборвана посередине или пусто.
Тогда выполни команды шага 2 ещё раз внимательнее.

---

## Шаг 3. Запустить автоматическую настройку

Теперь сервер сам всё настроит. Выполни две команды:

```bash
curl -fsSL https://raw.githubusercontent.com/san4ess1981-blip/vps-claude-setup/main/setup.sh -o /root/setup.sh
```

(эта команда скачивает инструкцию настройки — пройдёт молча, без надписей)

```bash
bash /root/setup.sh
```

**Что будет происходить:** 10–20 минут на экране будут бежать строчки —
сервер обновляется и устанавливает программы. Это нормально. Можно пойти
сделать чай, но окно браузера не закрывай.

⚠️ **Самое важное в конце!** Когда всё закончится, на экране появится
рамка со словами `СЕРВЕР ГОТОВ`. Там будут:

- **пароль пользователя dev** (длинная абракадабра из букв и цифр);
- **пароль панели VPN** (тоже абракадабра).

📝 **Перепиши оба пароля в блокнот или в заметки на телефоне!**
Больше они нигде не покажутся.

✅ **Как понять, что всё хорошо:** последняя строка —
`Готово. Сводка также сохранена в /root/setup-summary.txt`.

❌ **Если посередине выскочила красная ошибка** — перейди в раздел
«Аварийный выход» в конце шпаргалки.

---

## Шаг 4. Проверить, что сервер впускает твой компьютер

Теперь вернись на свой обычный компьютер.

1. Открой программу терминала: в Windows нажми клавишу **Win**,
   напечатай `Git Bash` и нажми Enter (подойдёт и **PowerShell**).
2. Вставь команду и нажми Enter:

```bash
ssh -p 51222 dev@146.103.57.168
```

3. Если спросит `Are you sure you want to continue connecting?` —
   напечатай `yes` и нажми Enter.

✅ **Правильно:** тебя впустили **без пароля**, появилась строка
`dev@...:~$`. Это значит: пропуск работает, новая дверь работает!

❌ **Если спросил пароль** — пропуск не подхватился. Вернись в чёрное окно
в браузере (шаг 1) и выполни:

```bash
cp /root/.ssh/authorized_keys /home/dev/.ssh/authorized_keys
chown -R dev:dev /home/dev/.ssh
```

Потом снова попробуй команду `ssh -p 51222 ...` со своего компьютера.

---

## Шаг 5. Проверить, что всё настроено правильно

На своём компьютере, в том же окне терминала, выполни две команды:

```bash
curl -fsSL https://raw.githubusercontent.com/san4ess1981-blip/vps-claude-setup/main/check.sh -o check.sh
```

```bash
bash check.sh
```

Скрипт подключится к серверу и проверит каждый пункт настройки.

✅ **Правильно:** все строки зелёные `[ OK ]`, в конце написано
`Сервер настроен корректно`.

❌ **Если есть красные `[FAIL]`** — сфотографируй экран и покажи мне (Кими),
разберёмся.

## Шаг 6. Включить VPN и войти в Claude

Claude не пускает пользователей из России напрямую, поэтому интернет-трафик
для входа пойдёт через твой сервер — для этого мы и ставили VPN.

1. Открой в браузере: `http://146.103.57.168:51821`
2. Введи **пароль панели VPN** (ты переписал его на шаге 3).
3. Нажми **New Client** (новый клиент) → придумай имя (например, `home-pc`)
   → **Create**.
4. Нажми **Download** — скачается файл настроек (конфиг).
5. Установи на компьютер программу **WireGuard** (бесплатная,
   скачать с wireguard.com) → **Импорт туннелей из файла** → выбери
   скачанный конфиг → нажми **Activate** (включить).
6. Проверка: зайди на сайт **whoer.net** — там должен быть написан IP
   `146.103.57.168`. Значит, твой интернет теперь идёт через сервер.
7. **Не выключая VPN**, зайди на **claude.ai** и войди в свой аккаунт
   (или зарегистрируйся).
8. Когда закончишь в панели VPN — закрой её снаружи, чтобы никто чужой
   не зашёл. Для этого на своём компьютере в терминале выполни:

```bash
ssh -p 51222 dev@146.103.57.168 "sudo ufw deny 51821/tcp"
```

---

## Шаг 7. Работа с Claude на сервере

Теперь обычный порядок работы, каждый раз:

```bash
ssh -p 51222 dev@146.103.57.168
```

```bash
tmux new -s work
```

```bash
claude
```

- При первом запуске Claude покажет ссылку для входа — открой её в браузере
  **при включённом VPN**.
- `tmux` — это «неубиваемое окно»: если интернет оборвётся, Claude
  продолжит работать на сервере. Вернуться в него: `tmux attach -t work`.

---

## Шаг 8. Убрать за собой

Пароли из шага 3 лежат на сервере в файлике — удалим его:

```bash
ssh -p 51222 dev@146.103.57.168 "sudo shred -u /root/setup-summary.txt"
```

И последнее: в панели Virtarix найди кнопку **Snapshot (снапшот)** и нажми —
это «фотография» настроенного сервера. Если в будущем что-то сломается,
сервер можно будет вернуть в сегодняшнее состояние одной кнопкой.

🎉 **Всё! Сервер настроен, Claude работает, двери заперты.**

## Аварийный выход (если что-то сломалось)

**Всегда помни:** чёрное окно в браузере (консоль Virtarix, шаг 1) работает
ВСЕГДА, даже если всё остальное сломано. Через него можно всё починить.

**Вернуть всё как было** (старая дверь 22, вход по паролю root) —
выполни в консоли Virtarix три команды:

```bash
rm -f /etc/ssh/sshd_config.d/99-vps-hardening.conf
```

```bash
systemctl restart ssh
```

```bash
ufw allow 22/tcp
```

После этого снова будет работать старый вход: `ssh root@146.103.57.168`
с паролем root.

**Совсем ничего не понятно / ничего не помогает:** в панели Virtarix есть
кнопка **Reinstall (переустановка)** — сервер вернётся к заводскому состоянию,
и можно начать эту шпаргалку с самого начала. Данные на сервере при этом
сотрутся, но там пока и нечего терять.

## Словарик

| Слово | Что это простыми словами |
|---|---|
| Сервер | Твой арендованный удалённый компьютер, работает 24/7 |
| SSH | Способ управлять сервером текстовыми командами через интернет |
| Порт | «Номер двери», в которую стучатся программы. У сервера 65 535 дверей |
| Ключ (SSH) | Электронный пропуск вместо пароля: длинный файл, который нельзя подобрать |
| root | Главный администратор сервера, может всё |
| dev | Твой рабочий пользователь на сервере (безопаснее, чем root) |
| VPN / WireGuard | «Туннель»: твой интернет-трафик идёт через сервер, сайты думают, что ты не в России |
| tmux | Программа-«держатель окон»: Claude работает внутри неё и не погибнет при обрыве связи |
| VNC-консоль | Экран и клавиатура сервера прямо в браузере — запасной вход |
| Снапшот | «Фотография» сервера для отката, делается в панели Virtarix |
